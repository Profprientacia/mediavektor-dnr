# Сайт конкурса «МедиаВектор: Траектория роста»

Готовый статический сайт для GitHub Pages.

## Публикация на GitHub

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите **всё содержимое** этой папки (файл `index.html` и папки `assets`, `docs`, `results`) в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
6. После публикации GitHub покажет адрес сайта в разделе Pages.

## Перед публикацией итогов конкурса

В папке `results` подготовлены места для файлов:
- `diplomy-i-sertifikaty.zip` — архив дипломов и сертификатов;
- `prikaz-ob-itogah.pdf` — приказ об итогах конкурса.

Замените эти файлы своими итоговыми документами, сохранив указанные имена. До добавления документов кнопки уже отображаются на сайте, но сами файлы будут доступны только после загрузки.

## Что уже включено

- эмблема конкурса;
- Положение конкурса в PDF;
- описание номинаций, требований и критериев оценивания;
- сроки проведения по Положению;
- ссылка на электронную форму заявки;
- ссылки на сайт и группу организатора.

Сайт адаптирован для телефонов и компьютеров. Все тексты и оформление можно редактировать в `index.html`.
